# DSO 576 – Beauty Review Intelligence

## Project Overview
This project analyzes customer reviews from the Amazon Reviews 2023 Beauty dataset to understand customer satisfaction and review characteristics.

## Dataset
The cleaned dataset is stored in the GitHub Releases section.

**File:** `beauty_cleaned.parquet`

## Research Question
How do review characteristics, including verified purchases and helpful votes, relate to product ratings?
